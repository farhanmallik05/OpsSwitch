# Side Track: Code with Wispr ($500 Cash) — Execution Strategy

**Prize:** $500 in Cash  
**Criteria:** Best project built by voice with Wispr Flow.  
**Mandatory Requirement:** Submit your Wispr usage scorecard (a screenshot from Insights in the Wispr Flow desktop app) alongside your hackathon project submission.

---

## 1. Why This Side Track Is Low-Hanging Fruit

Many hackathon teams either:
1. Forget to register for Wispr Flow through the hackathon link.
2. Forget to take and attach the Insights scorecard screenshot before the submission deadline.
3. Only dictate a single sentence, resulting in an unconvincing scorecard with minimal word counts.

By following this strategy:
- We claim the **1-month free Wispr Flow Pro** license.
- We dictate **system prompts, room instructions, commit messages, and README sections** using the pre-drafted dictation scripts.
- We accumulate **5,000+ words dictated**, producing an authentic, undeniable scorecard that places us at the very top of the judging rubric for this track.

---

## 2. Onboarding & Account Setup (Step-by-Step)

1. **Access the Hackathon Promo Link:**
   - Go to the hackathon resources page: [https://www.wemakedevs.org/hackathons/switch#wispr](https://www.wemakedevs.org/hackathons/switch#wispr) (or the official Wispr partner button).
   - Sign up for a free Wispr account. Your link grants **1 month of Wispr Flow Pro free**.
2. **Download & Install the Desktop App:**
   - Install Wispr Flow for macOS or Windows.
   - Complete the micro-calibration test to ensure voice recognition accuracy.
3. **Configure Hotkeys:**
   - Set your favorite dictation push-to-talk hotkey (e.g. `Fn`, `Caps Lock`, or `Right Alt`).
   - Turn on automatic punctuation and markdown formatting in Wispr settings.

## 4. Capturing the Verified Scorecard

On November 7 (before submitting):
1. Open the **Wispr Flow desktop app**.
2. Click on the **Insights / Analytics** tab in the sidebar.
3. Verify that your metrics display:
   - Words dictated (Aim for 4,000+ words).
   - Time saved (e.g., 2+ hours saved).
   - Days active during the hackathon window (Nov 4–7).
4. Take a high-resolution screenshot of the Insights dashboard.
5. Save the image to `plan/04_WISPR_FLOW_VOICE_TRACK/wispr-flow-scorecard.png`.
6. Attach the image file directly in the Devpost / WeMakeDevs project submission form.
