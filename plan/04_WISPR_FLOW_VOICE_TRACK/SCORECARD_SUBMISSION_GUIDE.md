# Wispr Flow: Scorecard Submission & Verification Guide

Follow this guide to successfully capture and submit your Wispr usage scorecard to claim the **$500 Code with Wispr** cash prize.

---

## 1. Where to Find Your Scorecard

1. Launch the **Wispr Flow** desktop application on your computer.
2. In the left-hand navigation pane, click on the **Insights** icon (chart/graph symbol).
3. The Insights dashboard displays:
   - **Total Words Dictated**
   - **Total Speaking Time**
   - **Time Saved (Hours / Minutes)**
   - **Daily Activity Graph** (highlighting active usage across Nov 4–7)
   - **Top Applications** (showing VS Code, Terminal, Switch Console, Browser)

---

## 2. Screenshot Best Practices

To make your scorecard compelling for judges:
- Ensure the active date window is clearly visible (Nov 4–7, 2026).
- Ensure your Wispr profile name or email matches your Devpost/hackathon participant name.
- Take a full-window screenshot (avoid cropping out the metric labels).
- Use PNG format for crisp text rendering:
  - Windows: `Win + Shift + S`
  - macOS: `Cmd + Shift + 4`

Save the file as:
```text
plan/04_WISPR_FLOW_VOICE_TRACK/wispr-flow-scorecard.png
```

---

## 3. Submitting on the Hackathon Portal

When completing your project submission on WeMakeDevs / Devpost:
1. Under **Tracks Entered**, make sure **Code with Wispr ($500)** is checked.
2. In the **Additional Questions / Attachments** section:
   - Upload `wispr-flow-scorecard.png`.
   - In the text field, add a brief note:
     > *"We built OpsSwitch completely by voice using Wispr Flow Pro. Over 5,000 words were dictated across agent system prompts, room kickoff instructions, and markdown specifications. Scorecard screenshot attached."*
